# いざかや 蛍（岐阜県各務原市）ホームページ提案

店舗提案用の1ページサイトです。**提案段階のため noindex・未デプロイ**。

## ローカル確認

```bash
npm run dev
# → http://localhost:3000/hotaru
```

本番ビルドでの確認は `npm run build && npm run start`。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `config/hotaru.ts` | **店舗情報・確認状況・画像・文言をすべて集約**（変更はここだけ） |
| `app/hotaru/page.tsx` | メタデータ（noindex）、フォント、構造化データ |
| `app/hotaru/_components/HotaruSite.tsx` | ページ本体（各セクション） |
| `app/hotaru/_components/Header.tsx` | 固定ヘッダー・スマホメニュー |
| `app/hotaru/_components/Reveal.tsx` | 控えめなフェードイン（JSなし・動きを減らす設定では無効） |
| `app/hotaru/_components/Logo.tsx` | 「蛍」テキストロゴ（提案デザイン） |
| `app/hotaru/hotaru.css` | 専用スタイル（`.hotaru` 配下にスコープ） |
| `public/images/hotaru/*.jpg` | 配信用画像（圧縮済み、1536×1024） |
| `public/images/hotaru/original/*.png` | 生成画像の原本 |

## 確認状況の反映方法

`config/hotaru.ts` の各項目は `{ value, verified, note }` の形です。

- `verified: false` … 画面に出しません（営業時間・定休日は「お電話でご確認ください」）
- 店舗に確認できたら `value` を正しい内容に直して `verified: true` にすると表示されます
  - `hours.businessHours` と `hours.regularHoliday` の**両方**を true にすると、表に実際の営業時間・定休日が出ます（構造化データにも営業時間が入ります）
  - `address.room` を true にすると住所に部屋番号が付きます
  - `facilities`（席数・お席・個室・駐車場・お支払い・喫煙）は true の項目だけ店舗情報の表に行が追加されます
- 実店舗の写真に差し替えたら `images.isImageOnly: false` で「写真はイメージです」表記が消えます

## 本番公開時の切り替え

1. `config/hotaru.ts` の `isProposal` を `false`（noindex 解除）
2. 本番URLが決まったら `seo.siteUrl` に設定（canonical・og:url・構造化データの url が出ます）
3. 独自ドメインで配信する場合は `next.config.ts` / `proxy.ts` にホスト別の書き換えを追加（takanaga・adofy と同じ方式）
4. ⚠️ ルートの `app/layout.tsx` に**他案件の Meta Pixel** が全ページ共通で入っており、`/hotaru` でも読み込まれます。公開前に除外方法を決めてください
5. OGP画像（SNSシェア用）は本番URL確定後に作成
