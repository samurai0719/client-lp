# 看護師転職サイトランキング（/nurse-ranking） 画像フォルダ

| ファイル | 用途 | 備考 |
|---|---|---|
| `hero.jpg` | ファーストビュー（1586×992） | 文字は画像に入っているため、HTMLで重ねない。写真素材はJPEGで置く（PNGは最適化時に文字色が崩れる不具合があったため） |
| `levwell-300x250.png` | レバウェル看護の正規広告素材（詳細カード） | 「看護師求人数23万件以上 ※2025年9月2日時点」の記載あり |

- ナース専科 転職・看護roo!転職は正規のロゴ・広告素材が未提供のため、文字で表示している（ロゴは生成しない）。
- 素材を追加したら `config/nurse-ranking.ts` の各サービスの `adImage` に設定する。
- 広告リンクは `config/nurse-ranking.ts` の `affiliateUrl` で一括管理（未設定の間は公式トップへ遷移）。
